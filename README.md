# Nomad

Nomad — личный путевой архив на FastAPI. Пользователь может хранить воспоминания
с фотографиями, отмечать места на карте, вести списки посещённых и желаемых стран
и управлять своим профилем.

## Возможности

- регистрация и авторизация по логину и паролю;
- имя и необязательное фото профиля;
- воспоминания с месяцем посещения, текстом и фотографиями;
- автоматический поиск координат через Nominatim и ручной выбор точки;
- карта мест, фильтры по году и стране;
- независимые карты посещённых и желаемых стран;
- тёмная и светлая темы;
- SQLite локально и PostgreSQL через `DATABASE_URL`;
- миграции существующей базы при запуске.

## Локальный запуск

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
Copy-Item .env.example .env
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`. Проверка состояния: `/health`.

## Тесты

```powershell
pytest -q
```

## Запуск на сервере

Команда запуска:

```text
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

Также приложен `Dockerfile`. Для SQLite и загруженных фотографий серверу нужен
постоянный диск, подключённый как `DATA_DIR`. Без постоянного диска следует
использовать PostgreSQL и внешнее хранилище фотографий.

Основные переменные окружения перечислены в `.env.example`. Файлы `.env`, базы
данных и каталог загрузок исключены из Git.

## Автоматическое обновление alwaysdata

Workflow `.github/workflows/deploy-alwaysdata.yml` обновляет приложение после
каждого push в `main` и проверяет `/health`. Uvicorn на alwaysdata запускается
с `--reload`, поэтому изменение файлов автоматически перезапускает приложение.
Для включения добавьте в GitHub Actions secret
`ALWAYSDATA_SSH_KEY`, а затем repository variable
`AUTODEPLOY_ENABLED=true`. Пока переменная отсутствует, workflow безопасно
пропускает развёртывание.
